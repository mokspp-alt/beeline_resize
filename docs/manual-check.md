# Ручная проверка в Figma

Всё, что можно проверить без Figma, покрыто тестами (`npm test`). Эти шаги закрывают оставшиеся задачи из
[`tasks.md`](../openspec/changes/add-figma-ai-resize/tasks.md) — их можно выполнить только в Figma Desktop.

## Подготовка

1. `npm install && npm run build`
2. `cp .env.example .env`, задайте `PLUGIN_TOKEN` (и при желании `LLM_PROVIDER`, ключ модели, `FIGMA_TOKEN`).
3. `npm run dev:backend` → `curl localhost:8787/health` отвечает `{"status":"ok"}`.
4. Figma Desktop → **Plugins → Development → Import plugin from manifest…** → `packages/plugin/manifest.json`.
5. Откройте тестовый файл, включите шесть библиотек Carnica (**Assets → Libraries**).
6. Запустите **Beeline Resize**, во вкладке «Настройки» введите `PLUGIN_TOKEN`.

## Чек-лист

| Задача | Что сделать | Ожидаемый результат |
|---|---|---|
| 1.2 | Импорт плагина из manifest | Плагин открывается, вкладки «Адаптация / Дизайн-система / Настройки» видны |
| 3.2 | Выделить фрейм со вложенным auto layout, инстансами Carnica и цветами на переменных | «Исходник: имя W×H»; после адаптации в результатах те же инстансы и привязки к переменным |
| 4.2 | Добавить размер 1000×120; ввести 0×120; сохранить набор, перезапустить плагин | 1000×120 в «Пользовательские»; для 0×120 — ошибка диапазона; набор ★ остаётся после перезапуска |
| 5.2 | Отключить `06_Carnica-UI-kit-WEB`, открыть «Дизайн-система» | Статус «не включена» и подсказка «Assets → Libraries»; при отключённых токенах — запрос подтверждения |
| 5.3 | Задать `FIGMA_TOKEN`, нажать «Сканировать дизайн-систему» | Нет ошибок доступа; в черновике `probeComponentKey` у UI-kit WEB, APP и icons |
| 5.4 | Проверить черновик, поставить `confirmed: true` нужным заменам, сохранить в `config/design-system.json` и закоммитить | `/config` отдаёт новый конфиг без перезапуска бэкенда |
| 8.3 | Запустить 15+ размеров и нажать «Отменить» в середине; затем «Перегенерировать» нетронутый и изменённый вручную результат | Созданные фреймы остаются; нетронутый заменяется на месте; изменённый сохраняется, рядом появляется «… v2» |
| 8.4 | Клик по пункту отчёта («legal скрыт», «нет App-аналога») | Выделяется соответствующий слой результата |
| 8.5 | После запуска нажать Cmd+Z один раз | Удаляются все фреймы этого запуска |
| 9.1–9.3 | Прогнать три исходника (web 1440, app 393×852, баннер 1080×1080) по всем группам с LLM и с `LLM_PROVIDER=none` | Отчёт без ошибок; «без AI» при выключенном провайдере; время полного прогона ≤ 60 с — записать в README |

Если что-то не так — пришлите скриншот отчёта плагина и вывод `npm run dev:backend`.
