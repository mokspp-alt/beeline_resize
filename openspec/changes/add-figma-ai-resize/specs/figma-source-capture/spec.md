# Spec Delta

## Purpose

Позволяет плагину взять один исходный макет из Figma и превратить его в полное, проверенное описание, на основе которого строится адаптация под другие размеры.

## ADDED Requirements

### Requirement: Single source frame selection
Плагин SHALL принимать в качестве исходника ровно один узел верхнего уровня типа Frame, Component или Instance на текущей странице. При любом другом выделении плагин MUST блокировать запуск адаптации и показывать понятное сообщение.

#### Scenario: Один фрейм выбран
- **WHEN** пользователь выделил один фрейм 1440×900 и открыл плагин
- **THEN** плагин показывает имя и размер исходника и делает доступной кнопку «Адаптировать»

#### Scenario: Пустое или множественное выделение
- **WHEN** ничего не выделено или выделено больше одного узла
- **THEN** кнопка «Адаптировать» недоступна и показано сообщение «Выберите один фрейм-исходник»

#### Scenario: Выделен не фрейм
- **WHEN** выделен текстовый слой или группа
- **THEN** плагин предлагает выбрать родительский фрейм и не запускает адаптацию

### Requirement: Source description capture
Плагин SHALL сериализовать исходник в описание макета: дерево узлов с типами, именами, геометрией, видимостью, constraints, параметрами auto layout, текстом и его стилями, заливками изображений, ссылками на компоненты, стили и переменные дизайн-системы.

#### Scenario: Auto layout и constraints сохраняются
- **WHEN** исходник содержит вложенный auto layout фрейм с gap 16 и элемент с constraints Left & Right
- **THEN** описание содержит направление, gap, padding и sizing этого фрейма и constraints элемента

#### Scenario: Привязки к дизайн-системе сохраняются
- **WHEN** у кнопки заливка привязана к переменной `color/primary`, а заголовок использует текстовый стиль `Heading/H1`
- **THEN** описание содержит ссылки на эту переменную и этот стиль, а не только вычисленные значения

#### Scenario: Инстанс компонента
- **WHEN** исходник содержит инстанс компонента из библиотеки с выбранным вариантом `Size=L`
- **THEN** описание содержит ключ компонента, набор свойств варианта и overrides инстанса

### Requirement: Source preview capture
Плагин SHALL по запросу экспортировать растровое превью исходника (PNG, не более 1600 px по длинной стороне) для передачи на бэкенд, если это разрешено настройками политики данных.

#### Scenario: Превью разрешено
- **WHEN** в настройках включена передача превью и запущена адаптация
- **THEN** вместе с описанием на бэкенд отправляется PNG-превью исходника

#### Scenario: Превью запрещено
- **WHEN** передача превью выключена
- **THEN** на бэкенд отправляется только структурное описание без растровых данных

### Requirement: Source validation warnings
Плагин SHALL до отправки на бэкенд проверить исходник и показать предупреждения о том, что ухудшает адаптацию: абсолютные позиции без constraints, отсутствующие шрифты, растровые слои с текстом, узлы вне границ фрейма.

#### Scenario: Отсутствует шрифт
- **WHEN** в исходнике используется шрифт, недоступный в текущей сессии Figma
- **THEN** плагин показывает предупреждение с именем шрифта и списком затронутых слоёв, а адаптация продолжается только после подтверждения пользователя
